# 한해설 Topic 글쓰기 가이드 (톤·형식)

가이드 글(`src/content/guides/*.md`)을 쓸 때 반드시 이 규칙을 따른다.
목적: 자동집계 매치 페이지와 달리 "사람이 쓴 고유 콘텐츠"로 읽히게 해서 검색 유입·체류·AdSense 품질을 끌어올린다.

## 무엇보다 — 팩트 우선
- 숫자(팀 수·경기 수·요금), 중계권, 일정, 소속팀 등은 **반드시 웹 검색으로 1차 확인**하고 검증된 것만 쓴다.
- 블로그·요약글 한 줄만 보고 단정하지 말 것. 출처 2개 이상 교차 확인이면 더 좋다.
- 확실치 않으면 "미정/확인 필요"로 정직하게 표기한다. 추측을 사실처럼 쓰지 않는다.
- 시즌은 이미 끝난 시즌이 아니라 **다가오는/현재 시즌** 기준인지 확인한다.

## 톤 — "진짜 사람이 쓴 블로그"처럼 (AI 티 안 나게)
- 친구한테 설명하듯 **캐주얼하게**. "~거든요", "~예요", "솔직히", "근데", "사실" 같은 구어체 OK.
- **개인 반응·감정을 섞는다.** "좀 쎄했는데", "아쉬웠어요", "마음 편하죠", "곤란하긴 하죠"처럼 글쓴이가 실제로 느끼는 듯한 말을 문장 사이에 자연스럽게 넣는다.
- 정보를 나열만 하지 말고 사람 말처럼 흐름이 이어지게. 문장 길이도 들쭉날쭉하게(짧은 문장도 섞기).
- 과장·상투구 금지 ("운명의 한 판", "역대급" 남발 X).

## 절대 하지 말 것 (AI 티 나는 것들)
- **줄표(—, ㅡ, –) 사용 금지.** 문장은 마침표·쉼표로 자연스럽게 끊는다.
- 문장 끝 "..." 로 흐리는 거 남발 금지.
- **인트로를 인용박스(>)로 요약하며 시작하지 말 것.** 그냥 사람처럼 첫 문장부터 자연스럽게 들어간다.
- **틀에 박힌 전환구 금지**: "결론부터 말하면", "정리하면 이래요", "한눈에 보면 이렇습니다" 같은 정형구 X. 표 앞도 "지금 순위는 이렇습니다", "요금은 이렇게 갈려요"처럼 자연스럽게.
- **칼각 병렬 볼드 헤더 지양**: "A하면?/B하면?/C하면?" 식 똑같은 구조 반복은 리스트 느낌(=AI 티). 자연스러운 문단으로 풀어쓴다.
- 소제목마다 이모지 박는 기계적 구성 금지.
- 모든 걸 표로 만드는 것 금지(표는 한눈 정리용 1개 정도).

## 형식
- **frontmatter**: title, description, date(YYYY-MM-DD), updated, category(예: 월드컵·해외축구·KBO).
- **줄바꿈**: 문단 짧게 끊어 숨통 트이게. 엔터 한 번이 곧 줄바꿈으로 렌더된다(marked breaks:true).
- **한눈에 보는 표 1개** 권장(순위·일정·요금 비교 등). 마크다운 표 위아래 빈 줄 필수.
- **내부 링크**: 관련 한해설 페이지로 건다(예: `[한해설 월드컵 페이지](https://haeseol.com/worldcup)`, /standings, 매치 페이지).
- 분량: 보통 500~900자 수준. 억지로 늘리지 말 것.

## 정체성
- 한해설의 핵심은 "**어디서 한국어 해설로 보나**". 모든 글에 중계처/무료 여부/한국어 해설 정보를 자연스럽게 엮는다.

## 한마디 — 쓰지 않는다
- 예전엔 맨 아래 `> ✍️ 한마디:` 박스를 넣었지만, 이제 **쓰지 않는다.** 본문에 이미 사람 말투·의견이 녹아 있으면 충분하다.
- 자동 초안에도 한마디 섹션을 넣지 않는다.

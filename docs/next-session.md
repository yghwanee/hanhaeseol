## 다른 PC 로 옮길 때 챙길 것

- `.env` 는 동기화가 안 된다. 다만 토스 키는 OneDrive 공용 파일에 있어 그대로 읽힌다
  (`npm run secrets` 로 확인). **VAPID·인스타·네이버 키는 아직 `.env` 에만 있다** —
  필요하면 `npm run secrets:push -- --key=<키이름>` 으로 같이 올릴 것.

## 1. 진단 — 병목은 노출이 아니라 클릭이다

네이버 30일 실측(2026-08-19 기준): **노출 119만 · 클릭 3.1천 · CTR 0.26%**

하루로 환산하면 노출 4만에 클릭 103. 노출이 부족한 게 아니다. **1,000번 보여서 2.6번 눌린다.**

같은 사이트 안에서 CTR 이 이만큼 갈린다.

| 자리 | CTR | 실측 |
|---|---|---|
| 순위 롱테일 `프리메라리가 순위 2025` | **21.3%** | 작업85 |
| 순위 롱테일 `프로축구 순위 2부` | **15.8%** | |
| 해설 쿼리 `kbs n sports 해설` | **7.3%** | 213클릭 |
| 편성표 쿼리 `kbs 스포츠 편성표` | 4.6% | 1,308노출 |
| 편성표 쿼리 `spotv 편성표` | **0.1%** | 17,642노출 → 22클릭 |
| 매치 쿼리 | **0.03%** | |
| **전체 평균** | **0.26%** | 119만 노출 |

**21%를 내는 자리가 이미 있는데 전체 평균이 0.26%다.** 산수로만 보면 119만 노출의 대부분이
CTR 이 사실상 0 인 자리에서 나온다는 뜻이다.

그 "0 인 자리"가 둘 중 무엇인지가 이번 플랜의 갈림길이다.

- **(가) 순위가 낮다** — 2페이지 밖이면 제목을 어떻게 고쳐도 안 움직인다
- **(나) 순위는 있는데 자리가 안 맞다** — 고칠 수 있다

작업85 는 (나) 가설로 제목을 고쳤고 클릭 +39% 가 나왔으니 부분적으로 맞았다. 하지만 CTR 0.26% 는
그대로다. **아직 아무도 노출의 순위 분포를 안 봤다.** 서치어드바이저에서 10분이면 나온다.

## 2. 핵심 가설 — 웹문서 블록에는 천장이 있다

유입의 **81.2%가 네이버**인데(빙 4.6% · 구글 1.8%, GA4 실측), 우리는 네이버의 **웹사이트(웹문서)
블록 하나**에만 존재한다.

네이버 통합검색은 한 화면에 블록을 쌓는다. 스포츠 쿼리면 대개 네이버 스포츠 위젯, 스마트블록(인기글),
블로그, 카페, 지식iN 이 위에 오고 웹사이트는 그 아래다. `/team/mls-로스앤젤레스-FC` 가 웹문서
**9위**여도 사람 눈에는 스크롤 한참 아래다.

그렇다면 CTR 0.26% 는 **제목 문제가 아니라 블록 문제**다. 웹문서 안에서 1위를 해도 그 블록이
화면 아래에 있으면 천장이 있다. 1차 플랜이 크기를 못 낸 이유가 여기일 가능성이 가장 크다.

**이건 추측이고, 확인은 사람이 15분이면 한다.** 네이버에서 아래 5개를 직접 검색해서
①우리가 어느 블록에 뜨는지 ②그 블록이 화면 몇 번째인지 ③블록 안 몇 번째인지를 적는다.

```
spotv 편성표
kbs n sports 해설
프리메라리가 순위 2025
로스앤젤레스 fc 일정
분데스리가 중계
```

가설이 맞으면 → 베팅 1 이 최우선.
가설이 틀리고 우리가 이미 화면 위쪽에 있는데도 안 눌린다면 → 제목·설명 문제라 베팅 1 을 뒤로 미루고
상위 20개 쿼리의 제목을 다시 짠다.

## 3. 세 개의 베팅

### 베팅 1 — 네이버 자사 표면에 들어간다 (가장 크고, 한 번도 안 해본 것)

유입의 81%가 네이버인데 우리는 네이버가 주는 표면 중 하나만 쓴다. 블로그·카페·지식iN 이 비어 있다.

🔴 **자동화가 안 된다.** 네이버 블로그 글쓰기 API 는 **2020년 5월 종료**됐다. 광고성 글 대량 생산이
사유였다. 손으로 올려야 한다. 이 프로젝트의 다른 모든 것과 달리 사람 시간이 든다.

그래서 **전량 미러링은 안 한다.** 43편을 다 옮기는 건 시간이 안 되고 중복 콘텐츠 위험도 있다.
**주 1편, 우리만 쓸 수 있는 문장이 든 글만** 올린다.

우리만 쓸 수 있는 문장이란 이런 것이다(작업109 실물).

> 이번 주 분데스리가 9경기가 전부 쿠팡플레이인데 한국어 해설은 4경기뿐이고, 그 4경기가 전부
> 코리안리거 경기다. 도르트문트·라이프치히 경기엔 안 붙는다.

이 문장은 웹 검색으로 안 나온다. 편성을 매일 쌓는 우리만 쓴다. 이런 글이 네이버 블로그 표면에
들어가면 웹문서 블록보다 위에서 경쟁한다.

**지식iN 은 더 직접적이다.** "○○ 경기 어디서 봐요"가 매일 올라오고 우리 데이터가 정답에 가장
가깝다. 주 3~5개, 링크는 절제한다(홍보로 읽히면 역효과).

**커뮤니티(에펨코리아·MLBPARK·디시)는 먼저 하지 않는다.** 사람은 거기 있지만 홍보 냄새에 가장
민감한 자리다. 블로그·지식iN 결과를 8주 보고 나서 판단한다.

판정 기준: 8주 뒤 GA4 에서 네이버 유입 중 블로그·지식iN 경유 세션이 잡히는지 + "한해설" 브랜드
검색량이 움직이는지. 기준은 지금 사실상 0.

### 베팅 2 — 재방문을 만든다 (검색 밖 유일한 채널, 산수가 제일 크다)

편성표는 **매일 쓰는 물건**인데 재방문 장치가 0 이다. 검색 유입은 매번 새로 이겨야 하지만
푸시 구독은 한 번 얻으면 계속 온다.

코드는 A단계가 이미 끝나 있다 — `src/lib/push/store.ts`(Vercel Blob) · `send.ts`(web-push VAPID) ·
`/api/push/subscribe` · `PushSubscribeButton`(VAPID 미설정이면 자동 숨김 = 현재 상태).

🔴 **6월부터 사용자 셋업 3개에 막혀 있다. 10분이면 끝난다.**

1. `npx web-push generate-vapid-keys`
2. Vercel 대시보드에서 Blob 스토어 생성(`BLOB_READ_WRITE_TOKEN` 자동 주입)
3. Vercel 시크릿 4개: `NEXT_PUBLIC_VAPID_PUBLIC_KEY` · `VAPID_PRIVATE_KEY` · `VAPID_SUBJECT` · `PUSH_TEST_KEY`

그 뒤 남은 빌드는 B(찜 UI = 경기 카드 별 버튼) → C(시작·결과 발송 GH Actions) → D(골 폴러).

산수:

```
하루 110명 × 구독 전환 3% = 3.3명/일
90일 누적 ≈ 300명
하루 1회 알림 × 클릭률 25% = 75 재방문/일
```

전환 3%·클릭 25% 는 보수적으로 잡은 값이다(스포츠 알림은 시의성이 있어 클릭률이 높은 편).
그래도 **90일 뒤 +75/일, 지금 전체 유입의 +68%** 다. 그리고 검색과 달리 **누적된다** —
구독자는 안 줄고 매일 새로 이길 필요가 없다.

이 문서에서 가장 큰 단일 숫자이고, 막힌 게 사용자 셋업 10분이다.

## 4. 안 할 것 (명시해 둔다)

### 1. 🔴 소셜 3채널 — 확대 금지. 측정부터 한다

지금까지 들어간 엔지니어링이 이 프로젝트에서 가장 크다(게시 로그·감시견·따라잡기·커버 생성·
조사 처리·중복 방지 가드 수십 건). 그런데 성과는 이렇다.

- 인스타: **186 게시물 → 팔로워 4 · 좋아요 0~1**
- 틱톡: 0 조회 (게시 자체는 정상임을 작업105 에서 증명)
- 유튜브 쇼츠: 게시일 하루 합계 ~304

**그리고 이게 사이트 유입에 얼마나 기여하는지 한 번도 안 봤다.** 볼 수 있다 —
`next.config.mjs` 에 `/ig` `/yt` `/tt` → `utm_source` 리다이렉트가 이미 있다.
GA4 에서 소셜 유입 세션 수가 바로 나온다.

**판정**: 30일 소셜 경유 세션이 100 미만이면 게시를 하루 2회 → 1회(저녁만)로 줄이고,
그 시간과 컨텍스트를 베팅 1 에 쓴다. 저녁이 아침보다 2~5배 잘 나오므로 아침을 뺀다.

틱톡 수동 업로드 실험(작업105)은 예정대로 한다. **그 결과 전에는 틱톡 코드를 건드리지 않는다.**

### 2. 매치 페이지 색인 복원 금지

실측으로 죽인 자리다. 1,330장이 GSC 3개월 노출 0·클릭 0 인데 ISR Writes 96% 와 Active CPU

켜지 않는다.**

### 3. 편성표 쿼리 추가 투자 금지

`spotv 편성표` 17,642노출 → 22클릭(0.1%). SPOTV 는 공식 편성 페이지가 있어 제목으로 못 이긴다.
같은 유형인 `kbs 스포츠 편성표` 는 4.6% 인데, 이건 KBS 가 그 자리를 안 지키기 때문이다.
**공식 페이지가 있는 플랫폼의 편성표 쿼리는 버린다.**

### 4. 애드센스 재도전 금지

병목은 승인이 아니라 트래픽이다. 애드핏 실측이 **월 540원 · eCPM 118원**이었다. 유입이
자릿수로 바뀌기 전에는 광고 작업의 기대값이 0 이다.

### 5. 페이지 대량 생산 금지

선수 페이지는 데이터가 나오기 전까지 보류(작업58 사유 유효). 1차 플랜에서 배운 것은
"페이지를 더 만드는 것"이 아니라 "만든 페이지가 보이는 자리에 있는가"가 병목이라는 점이다.

# 커버 후킹 + 히어로 선정 개편 설계

작성 2026-08-05 · 상태: 사용자 검토 대기

## 왜 하나

소셜 커버(인스타 캐러셀 1장 = 릴스 cover = 쇼츠 첫 프레임)에 후킹이 부족하다는 지적에서
시작했는데, 코드를 뜯어보니 결함이 두 층이었다.

**L1 — 주인공이 매일 같다.** `heroScore()` 의 `koreanPlayer` 30점이 단일 최대 가중치라
평일에는 MLB 코리안리거가 상시 1위다. 실측(2026-08-05):

```
 55 | MLB          | 09:05 | 텍사스 vs 샌프란시스코   ← 이정후
 30 | 클럽 친선경기  | 20:00 | AC 밀란 vs 인터 밀란     ← 밀라노더비
 20 | 쿠팡플레이시리즈| 19:00 | 팀 K리그 vs 맨시티       ← 16위, 롯데vs키움과 동점
```

맨시티가 20점인 이유는 `BIG_TEAMS` 가 **리그별 맵**이라 리그명이 정확히 안 맞으면
팀 점수가 0이 되기 때문이다. `BIG_TEAMS.프리미어리그` 에 맨시티가 있어도 이 경기의
리그는 `쿠팡플레이 시리즈` 라 조회 자체가 안 된다. 첼시·유벤투스·밀란도 같은 이유로 0점.
**리그가 아니라 팀이 값어치인 경기인데 팀 가중치가 리그에 종속돼 있다.**

**L2 — 커버에 후킹이 없거나 약하다.** 아침판(`renderHookV7`)은 후킹 문구가 아예 없고
제일 큰 글자가 날짜 240px이다. 저녁판(`renderReelTitleText`)은 후킹이 있지만 강조가 없어 평평하다.

L1이 위 레버다. 주인공이 매일 같으면 문구를 아무리 고쳐도 같은 그림이 나온다.

## L1 · 히어로 선정 변경

`src/lib/hero-pick.ts`.

### 1. 표기 정규화

`norm(s) = s.replace(/\s+/g, "")` 를 팀명 비교 전면에 적용한다.
데이터는 `AT. 마드리드`(공백 있음)인데 `BIG_TEAMS` 는 `AT.마드리드` 라 리그가 맞아도 못 잡던 버그가 있다.

### 2. 리그 무관 글로벌 빅클럽

```ts
const GLOBAL_BIG_CLUBS = new Set([
  "맨시티", "맨유", "리버풀", "아스날", "첼시", "토트넘",
  "레알 마드리드", "바르셀로나", "아틀레티코 마드리드", "AT.마드리드",
  "바이에른 뮌헨", "도르트문트",
  "유벤투스", "인터 밀란", "AC 밀란", "나폴리",
  "PSG", "파리 생제르망",
].map(norm));
```

리그명과 무관하게 팀명으로만 매칭한다. 둘 다 빅클럽 20점 / 한쪽만 12점.
기존 리그 기반 `scoreBigMatchup` 결과와 `Math.max` 로 합친다(중복 가산 금지).

유럽 축구만 넣는다. MLB·KBO·NBA 는 이미 리그 스코프 `BIG_TEAMS` 로 점수를 받고 있고,
여기에 또 넣으면 코리안리거 MLB 가 다시 부풀어 이번 개편의 목적이 뒤집힌다.

### 3. 이벤트성 대회 등급

지금은 등급표에 없어 전부 최하 5점이다.

| 리그 | 등급 |
|---|---|
| `쿠팡플레이 시리즈` | 15 (내한 독점 중계) |
| `클럽 친선경기` | 10 |
| `카라바오컵` | 10 |

### 4. 한국선수 가중치 30 → 18

**이게 실제로 작동한 유일한 레버다.** 글로벌 빅클럽 세트와 이벤트 등급만 넣고
`koreanPlayer` 를 30으로 두면 7일 시뮬레이션 결과가 현행과 **완전히 동일**했다.
30점이 워낙 커서 나머지 조정이 전부 묻힌다.

트레이드오프: 이정후·김혜성은 실제 검색량이 있는 키워드이고 쇼츠 제목은 검색 대상이다.
18로 낮춰도 코리안리거는 7일 중 4일 히어로로 남는다(아래 표) — 완전히 밀려나지 않는다.

### 5. 내한경기 가점 +10

리그가 `쿠팡플레이 시리즈` 이고 양 팀 중 하나가 `GLOBAL_BIG_CLUBS` 면 +10.
국내 화제성은 상대가 누구냐보다 "그 팀이 한국에 온다"가 크다.
이 가점이 없으면 오늘 `팀 K리그 vs 맨시티`(42점)가 `첼시 vs 유벤투스`(45점)에 밀린다.

### 6. 연속 방지 −12

직전 2일 히어로에 등장한 팀이 포함되면 −12.
`8/10·8/11 샌프란시스코 2연속` 을 갈라준다. "매일 같은 얼굴"이라는 원래 불만에
직접 대응하는 항목이라 넣는다.

### 검증 — 7일 시뮬레이션

| 날짜 | 현행 | 개편안 |
|---|---|---|
| 8/05 | 텍사스 vs 샌프란시스코 | **팀 K리그 vs 맨시티** 19:00 |
| 8/06 | 시카고 컵스 vs LA 다저스 | 시카고 컵스 vs LA 다저스 (김혜성) |
| 8/07 | LG vs KIA | LG vs KIA |
| 8/08 | 애리조나 vs LA 다저스 | **첼시 vs AC 밀란** 21:00 |
| 8/09 | 샌프란시스코 vs 디트로이트 | **맨시티 vs AT. 마드리드** 18:30 |
| 8/10 | 샌프란시스코 vs 디트로이트 | 샌프란시스코 vs 디트로이트 |
| 8/11 | 샌프란시스코 vs 휴스턴 | LA 다저스 vs 캔자스시티 |

서로 다른 매치업 6/7 → 7/7. 코리안리거는 4/7로 남는다.

`8/07 LG vs KIA` 는 버그가 아니다. 그날은 유럽 빅클럽 경기가 0이고 MLB 코리안리거
경기도 한국어 해설이 없어(배지환 피츠버그전 03:10 현지 해설) KBO 가 실제로 최선이다.

## L2 · 커버 디자인

두 슬롯 모두 **풀이미지 + 하단 텍스트** 구조로 통일한다.
지금까지는 아침이 좌패널(V7), 저녁이 풀이미지였다.

### 슬롯별 사양

| | 아침판 | 저녁판 |
|---|---|---|
| 레이아웃 | 작은 윗줄 + 큰 아랫줄 (대비 2줄) | 큰 한 줄 + 설명 줄 |
| 액센트 | 앰버 `#ffb02e` | 라임 `#8fff3d` |
| 프레임 | 오늘 | 내일 |
| 예시 | `오늘 저녁 7시 · 쿠팡플레이` / **`맨시티 오늘 옵니다`** | **`내일 새벽 3시 20분`** / `김혜성 출전 · 한국어 해설 16경기` |

문구 구조가 상하 반대라 레이아웃 통일 손실을 메운다.

### 중복 위험에 대한 판단

실제로 충돌하는 쌍은 **같은 날짜를 대상으로 하는 두 게시물**이다.
저녁판은 *내일* 경기를, 다음날 아침판은 *오늘* 경기를 올리므로 대상 날짜·히어로·경기 수가 같다.
작업82에서 유튜브가 배포를 끊은 게 정확히 이 쌍이다.

레이아웃까지 통일해도 남는 차별 요소:

| 요소 | 아침 | 저녁 |
|---|---|---|
| 액센트 색 | 앰버 | 라임 |
| 배경 사진 | `pickHookImage(date,"morning")` | `pickHookImage(date,"evening")` |
| 프레임 문구 | 오늘 | 내일 |
| 문구 풀 | MORNING | EVENING (2칸 밀기) |
| 영상 생성 경로 | `make-reel.ts` (v1) | `make-reel-v2.ts` (v2) |
| 레이아웃 | 같음 | 같음 |

여섯 중 다섯이 다르다. 작업82 사고 때는 제목이 **글자까지 동일**했고 배경 이미지도 같았다.
그리고 유튜브가 판정하는 대상은 커버가 아니라 영상이며, 영상 생성 경로 v1/v2 차이는 그대로 남는다.
통일되는 것은 인스타 캐러셀 1장뿐이다.

### 세부 규칙

- **날짜는 흰색.** 지금 저녁판은 날짜가 액센트 색이라 후킹과 강조가 둘로 갈린다. 초록/앰버는 후킹의 강조 조각에만 준다.
- **줄바꿈은 어절 단위.** 강조 조각 기준으로 자르면 `맨시티가` 가 `맨시티 / 가` 로 조사가 떨어져 나간다. 한국어에서 조사는 앞말에 붙여 쓴다.
- **시각은 읽는 대로.** `03:20` → `새벽 3시 20분`. 기존 `speakTime()` 재사용.
- **강조 조각은 히어로에서 뽑는다.** 인물형이면 선수명, 팀명형이면 팀명, 시간압박형이면 시각.

### 문구 풀

한국선수가 있으면 이름, 없으면 팀명을 앞에 건다(기존 `isPlayer` 분기와 동일 규칙).

풀 크기는 **슬롯당 8개**로 늘린다. 현재 `shorts-title.ts` 4개 · `reel-title-card.ts` 3개라
같은 틀이 3~4일마다 돌아온다. 8개면 한 주 안에서 겹치지 않는다.
틀은 사람이 쓰고 코드가 값만 채우므로 늘리는 비용은 배열에 줄을 더하는 것뿐이다.

LLM 로 매일 새 문장을 생성하는 방식은 채택하지 않는다. 비용·검증 부담이 붙고,
봇처럼 보이게 만든 원인은 틀 반복이 아니라 작업82에서 실제로 터진 "글자까지 동일"이다.

## 미채택

- **이미지 톤 보정(아침 따뜻 / 저녁 차갑).** 렌더해서 비교했다. 배경 사진이 어차피 슬롯별로
  다르게 뽑히므로 추가 기여가 거의 없는데 사진 색을 건드리는 비용은 있다.
  덧붙여 `sharp.tint()` 는 이미지를 그 색조로 매핑해 사실상 흑백을 만든다 — 쓰지 말 것.
- **아침 좌패널(V7) 유지안.** 사진을 안 가리는 장점이 있으나 하단 40%가 비고,
  후킹이 두세 줄로 쪼개진다(실효 폭 293px, 50%로 넓혀도 두 줄).
- **선수/팀 대신 순위·연승 맥락.** KBO 만 남는 날(8/07 같은)에 후킹 재료가 약해지는 문제는
  `standings` 데이터로 풀 수 있으나 이번 스코프 밖이다.

## 영향 범위

| 파일 | 변경 |
|---|---|
| `src/lib/hero-pick.ts` | 가중치·글로벌 빅클럽·이벤트 등급·내한 가점·연속 방지·표기 정규화 |
| `src/lib/cover-hook.ts` (신규) | 슬롯별 후킹 문구 풀 + 강조 조각 선정 |
| `src/lib/reel-title-card.ts` | 슬롯별 레이아웃·액센트, 날짜 흰색, 어절 단위 줄바꿈 |
| `src/lib/hook-card.ts` | `renderHookV7` 은 남기되 아침 경로에서 분리 |
| `src/scripts/post-instagram-all.ts` | `HHS_LEGACY_MORNING` 분기에서 아침도 새 커버 사용 |
| `src/scripts/make-reel.ts` | 아침 첫 프레임(`main-reel-*.png`) 소스 교체 |
| `src/lib/shorts-title.ts` | 문구 풀 4 → 8, 커버와 문구 재료 공유 |

`renderHookV7` 을 지우지 않는다. 아침 릴스 v1 이 세이프존 변형(`pad=85`)을 쓰고 있어
경로를 한 번에 갈아엎으면 영상 쪽이 같이 깨진다. 새 커버로 옮긴 뒤 실렌더로 확인하고 정리한다.

## 위험과 관찰

- **작업82 관찰창이 아직 안 끝났다.** 8/04 저녁부터 쇼츠 피드 배포가 눌린 상태이고
  회복 판정에 1~2주가 필요하다. 지금 커버를 바꾸면 회복/악화의 원인을 가르기 어려워진다.
  → 배포 시점을 사용자가 정한다. 관찰을 우선하면 코드만 준비하고 머지를 미룬다.
- 히어로가 유럽 빅클럽로 옮겨가면 `이정후 한국어 중계` 류 검색 유입이 줄 수 있다.
  쇼츠 제목은 검색 대상이므로 2~4주 뒤 `social-stats` 로 확인한다.
- 유럽 리그 개막(8/22) 후에는 EPL·분데스가 S등급이라 내한 가점 없이도 상위로 올라온다.
  개막 후 가중치를 재확인한다.
